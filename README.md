# BondStats Swiss Financial System

Isolated Astro build for the BondStats Swiss Financial System SEO cluster.

- 100 curated concept pages
- 1 hub page
- 1 XML sitemap containing exactly 101 URLs
- stable `@swiss/*` import alias (no fragile deep relative data imports)
- validation rejects wrong entry counts, duplicate/invalid slugs, or missing route files

Intended production route: `/markets/swiss-financial-system/`.
This repository is intentionally isolated from `bondstats-site`; integration should happen only after a successful build.
